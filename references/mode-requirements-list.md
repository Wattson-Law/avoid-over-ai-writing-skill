# 模式：需求清单

## 适用范围

适用于包含项目背景、需求详情、识别项表格和供应商方案要求的短篇需求文档。输入若含修订记录，只读取接受修订后的可见结果；输出不得继承修订标记。

## 内容结构

按输入已有信息组织，不新增封面、目录或说明页：

1. 文档标题；
2. `一、项目背景`；
3. `二、需求详情`；
4. 需求组：`1. 需求名称`、`2. 需求名称`；
5. 需求组内子项：`（1）子项名称`；
6. 再下一层明细：`1）明细内容`；
7. 识别需求标题后紧跟表格；
8. `三、供应商方案要求`，分组和组内响应项使用相同层级规则。

在 `editorial` 模式下只改善需求句的完整性与可读性，不扩大功能范围。优先采用“条件/场景 → 能力动作 → 对象 → 输出或响应”的信息顺序。

## 页面和字体

| 角色 | 规范 |
| --- | --- |
| 页面 | A4 纵向，单节；上/下 1.00 英寸，左/右 1.25 英寸 |
| 文档标题 | 宋体 + Times New Roman，18 pt，加粗，黑色，居中，1.2 倍行距，段前 0、段后 4 pt |
| 一级业务章节 | 宋体 + Times New Roman，16 pt，加粗，黑色，左对齐，段前 6 pt、段后 4 pt |
| 正文和编号层级 | 仿宋 + Times New Roman，16 pt，常规，黑色，左对齐 |
| 正文段落 | 首行缩进 32 pt，1.5 倍行距，段前/段后 0，孤行控制 |
| 表题 | 宋体 + Times New Roman，12 pt，黑色，居中，仅使用 `表1`、`表2`…… |
| 列标题行 | 宋体 + Times New Roman，12 pt，加粗，黑色，水平/垂直居中 |
| 表体 | 宋体 + Times New Roman，12 pt，黑色，水平/垂直居中 |

除非用户在当前任务中明确要求保留彩色文字，文档标题、各级标题、正文、表题及表格文字的每个 run 本身或其有效字符样式必须解析为明确黑色 `000000`；输入文件原有颜色本身不构成保留依据。不得使用“自动”颜色或主题颜色。字体、字号和颜色可由有效样式提供；存在冲突或继承不明确时再在 run 级显式设置。

文档标题、一级业务章节以及被识别为独立标题的需求/响应编号段落，在套用规范前先清除影响目标样式的原稿直接格式，包括字体、字号、加粗、颜色、主题色、突出显示及段落缩进，再显式重设上述格式；这些标题段落不得首行缩进或悬挂缩进，必须启用“与下段同页”。独立需求/响应标题如无单列规范，使用 1.5 倍行距、段前/段后 0；普通编号需求句仍按正文处理，不因编号开头被误套标题格式。

## 黑白识别表

- 每张表上方添加居中的独立表题，按全文出现顺序仅写 `表1`、`表2`……，不根据识别项、类别或章节名称自行拟题；
- 表格统一白底、黑字，不使用蓝色或其他彩色填充；
- 从有色表头改为白底时，必须同时逐 run 将列标题文字重设为黑色 `000000`，并清除其主题色、色调和阴影属性；不得只移除单元格填充而保留白字或主题色；
- 外框和内部网格均使用 `0.5 pt` 黑色实线，不加粗外框；
- 单元格边距四边 15 twips；
- 单元格段落单倍行距、无首行缩进、段前/段后 6 pt；
- 列标题行跨页重复，行高自动；
- 表格左边界与版心对齐，不超出版心；
- 养护类表通常为 `序号/类别/识别项`，路政类表通常为 `序号/识别项`；只根据输入已有列决定结构；
- 新增序号列时从 1 连续编号，不拆分、合并或补写识别项。

## 分页规则

- 标题与下一段同页；
- 表格紧跟对应需求标题；
- 删除仅承担旧版占位作用的空白段落；
- 本模式保持单节，不新增分节符；同一页面切换位置若已有手动分页符或标题“段前分页”，只保留一种，不在其后再叠加分页符或分节符；
- 删除分页符前后的纯空白占位段后再检查分页结果，最终不得因连续分页符、空段或“分页符 + 段前分页”组合产生空白页；
- 不为压缩页数改变字号、页边距或表格内容；
- 不出现页眉、页脚、页码或装饰性空白页，除非输入明确要求保留。

# 模式：科技研发项目立项申请书

## 适用范围

适用于科技研发项目立项阶段的正式申报材料。该模式强调立项依据、研究内容、方法路线、预期成果和申报审核，不得套用实施大纲的预算附件顺序。

## 固定结构

输入有固定表单时保持其栏目、签章区和表格顺序。常见章节为：

1. 立项背景；
2. 国内外研究概况及可行性分析；
3. 项目研发目标及主要内容；
4. 研究开发方法及技术路线；
5. 项目考核目标；
6. 推广应用前景及经济效益预测；
7. 申报单位和协作单位及分工；
8. 项目进度计划；
9. 项目经费预算；
10. 项目负责人及主要研究人员；
11. 申报单位和协作单位审核意见。

只有输入本身包含对应信息时才保留这些章节；不补写缺失章节。`editorial` 模式不调整一级章节顺序。

## 页面与封面

- 保留并更新输入已有的自动目录；输入没有目录时不因套用本模式自行新增，只有用户在当前任务中明确要求生成目录时才按 [toc-generation.md](toc-generation.md) 在封面后、正文前新增；
- 正文页面为 A4 纵向，上/下 1.00 英寸、左/右 1.25 英寸；
- 宽人员表或预算表可使用独立 A4 横向分节：上/下 1.25 英寸、左/右 1.00 英寸；
- 封面单位名称居中，宋体或原模板指定字体，18 pt，加粗、黑色；
- 封面主标题使用方正小标宋简体，26 pt，加粗、黑色，居中，段前/段后约 15.6 pt；
- 项目名称、申报单位、协作单位、负责人、经费和起止年限保留原有表单排列，正文级信息使用 14 pt 仿宋；
- 输入模板含独立封面落款日期且原设计为加粗时，日期保持加粗、黑色；不得把项目起止年限等普通表单字段误判为封面日期；
- 封面不添加页眉页脚，正文页码按输入模板保留。
- 新建横向分节时，横向表前、表后各使用所需的一个分节符，并移除同一位置已有的手动分页符或“段前分页”；不得叠加“分页符 + 下一页分节符”。除非固定模板明确要求奇数页/偶数页起始，分节一律不用奇数页/偶数页类型；横向内容结束后恢复纵向页面设置。
- 保留承载固定表单、签章区、页眉页脚或页面设置的必要分节，只清除重复分页控制和纯占位空段；最终分页不得出现由连续分节符、连续分页符或二者叠加形成的空白页。

## 标题和正文

| 角色 | 规范 |
| --- | --- |
| 一级章节 | 仿宋_GB2312，16 pt，加粗，黑色，左对齐，段前/段后 12 pt |
| 二级标题 | 仿宋，14 pt，加粗，黑色，左对齐，段前/段后约 6 pt |
| 三级及任务标题 | 仿宋，14 pt，加粗，黑色，左对齐，1.5 倍行距 |
| 正文 | 仿宋 + Times New Roman，14 pt，常规，黑色，两端或左对齐 |
| 正文段落 | 首行缩进 28 pt，1.5 倍行距，段前/段后 0 |
| 图题 | 宋体或仿宋，12 pt，黑色，居中，保留原有编号与文字 |
| 表题 | 宋体或仿宋，12 pt，黑色，居中，仅使用 `表1`、`表2`…… |

标题与下一段同页，避免孤立标题。除非用户在当前任务中明确要求保留彩色文字，封面、标题、正文、图题、表题和表格文字的每个 run 本身或其有效字符样式必须解析为明确黑色 `000000`；输入文件原有颜色本身不构成保留依据。不得使用“自动”颜色或主题颜色。字体可由有效样式提供；存在冲突或继承不明确时再在 run 级显式设置。缺少方正小标宋简体时保留字体声明，不自行换成装饰字体。

仅对表格外、被识别为独立标题的段落清除影响目标样式的原稿直接格式，包括字体、字号、加粗、颜色、主题色、突出显示及段落缩进，再显式重设对应字体、字号、加粗、黑色、行距和段间距。一级至三级标题不得首行缩进或悬挂缩进，必须启用“与下段同页”；固定表单的单元格标签、签章区和空白填写区不得套用标题样式或被清空直接格式。

## 黑白表格与图示

- 使用正式申报书的黑白细网格，不套用蓝色业务表；
- 每张业务内容表上方添加居中的独立表题，按出现顺序仅写 `表1`、`表2`……，不根据表格内容自行拟题；仅用于封面字段排列、签字盖章、审核意见或页面布局的结构表不参与表题编号；
- 表格统一白底、黑字，外框和内部网格均使用 `0.5 pt` 黑色实线，不加粗外框；
- 从有色表头改为白底时，必须同时逐 run 将列标题文字重设为黑色 `000000`，并清除其主题色、色调和阴影属性；不得只移除单元格填充而保留白字或主题色；
- 具有真实列标题行的业务表将该行加粗并水平/垂直居中，跨页时重复；结构表不得把第一行误判为列标题或强制重复，表体按字段性质居中或左对齐；
- 表格字体优先仿宋，通常 10.5 至 14 pt；在不裁切的前提下按列数和表单密度选择统一字号；
- 保留合并单元格、签字盖章区、空白填写区、序号和备注；
- 宽表使用横向分节，不通过极小字号强行塞入纵向页面；
- 技术路线图、架构图和公式居中，保持清晰度、图题和原有图编号；不得用文字猜测缺失图示内容。

## 表达重点

- 立项背景由宏观依据逐步落到项目场景和具体问题；
- 研究现状按技术子领域组织，并保留原稿已有不足判断；
- 研发目标、创新点、研究内容、研究方法和考核指标使用一致的任务名称；
- 研究方法说明对象、步骤、集成和验证，不新增技术路线；
- 成果、经济效益和推广内容保持原稿判断强度，不扩张应用范围。
